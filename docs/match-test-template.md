## 当日運用

2. LIVE画面でスコア状況を選ぶ。

### ハーフタイム（専用画面を使う場合）

帰宅後または編集可能な環境で、対象試合の`status`を`half_time`へ、スコアを前半終了時点へ更新する。試合中のスマホ操作だけでは専用画面へ切り替わらない。

### 試合後

対象試合の`status`を`finished`へ、最終スコアを更新する。各三策の`result`を`hit` / `partial` / `miss`へ、必要に応じて`resultComment`を追加する。
